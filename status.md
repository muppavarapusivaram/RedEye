If all endpoints return 404, this typically indicates the Generative AI API is not enabled in Google Cloud Console or the API key lacks model access permissions.

- 2025-11-12: Implemented dynamic model discovery for Gemini API: Added `_list_available_models()` function that queries the Gemini API to discover which models are actually available for the user's API key. This solves the issue where free tier API keys may have access to different models. The system now automatically detects available models and uses them, falling back to common model names if the list API fails. This ensures compatibility with both free tier and paid tier API keys.
